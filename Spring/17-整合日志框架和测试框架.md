# 1. 整合 log4j2

Spring5 框架自带了通用的日志封装，也可以整合自己的日志；
Spring5 移除了 LOG4jConfigListener（log4j），官方建议使用 log4j2。

导入 log4j2 依赖

```xml
<dependency>
    <groupId>org.apache.logging.log4j</groupId>
    <artifactId>log4j-slf4j2-impl</artifactId>
    <version>2.25.3</version>
</dependency>
```

在 resources 目录下准备 log4j2.xml 配置文件：

```xml
<?xml version="1.0" encoding="UTF-8"?>
<Configuration status="INFO">
    <Appenders>
        <Console name="Console" target="SYSTEM_OUT">
            <PatternLayout pattern="%d{YYYY-MM-dd HH:mm:ss} [%t] %-5p %c{1}:%L - %msg%n" />
        </Console>
    </Appenders>
    <Loggers>
        <Root level="info">
            <AppenderRef ref="Console" />
        </Root>
    </Loggers>
</Configuration>
```

# 2. 整合 junit4

pom.xml

```xml
<dependency>
    <groupId>junit</groupId>
    <artifactId>junit</artifactId>
    <version>4.13.2</version>
    <scope>test</scope>
</dependency>
<dependency>
    <groupId>org.springframework</groupId>
    <artifactId>spring-test</artifactId>
    <version>${spring.version}</version>
    <scope>test</scope>
</dependency>
```

未引入 spring-test 时，在测试类中要写代码获取 ApplicationContext 和其他被 Spring 管理的 bean 对象：

```java
package com.arc.spring.test;

import com.arc.spring.service.AccountService;
import org.junit.Before;
import org.junit.Test;
import org.springframework.context.ApplicationContext;
import org.springframework.context.support.ClassPathXmlApplicationContext;

public class TransactionByAnnotationTest {

    ApplicationContext applicationContext;
    AccountService accountService;

    @Before
    public void getApplicationContext() {
        applicationContext = new ClassPathXmlApplicationContext("transaction-by-annotation.xml");
        accountService = applicationContext.getBean(AccountService.class);
    }

    @Test
    public void testTransaction() {
        System.out.println(accountService);
    }

}
```

引入 spring-test 后，可以自动注入：

```java
package com.arc.spring.test;

import com.arc.spring.service.AccountService;
import org.junit.Test;
import org.junit.runner.RunWith;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.test.context.ContextConfiguration;
import org.springframework.test.context.junit4.SpringJUnit4ClassRunner;

@RunWith(SpringJUnit4ClassRunner.class) // 指定测试支持类
@ContextConfiguration("classpath:transaction-by-annotation.xml") // 指定核心配置文件位置
public class SpringJunit4Test {

    @Autowired
    private AccountService accountService;

    @Test
    public void springJunit4Test() {
        System.out.println(accountService);
    }

}
```



# 3. 整合 junit5

依赖：

```xml
<dependency>
    <groupId>org.junit.jupiter</groupId>
    <artifactId>junit-jupiter-api</artifactId>
    <version>5.14.3</version>
    <scope>test</scope>
</dependency>
```

测试类：

```java
package com.arc.spring.test;

import com.arc.spring.service.AccountService;
import org.junit.jupiter.api.Test;
import org.junit.jupiter.api.extension.ExtendWith;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.test.context.ContextConfiguration;
import org.springframework.test.context.junit.jupiter.SpringExtension;

@ContextConfiguration("classpath:transaction-by-annotation.xml")
@ExtendWith(SpringExtension.class) // 替代了 @RunWith(SpringJUnit4ClassRunner.class)
public class SpringJunit5Test {

    @Autowired
    private AccountService accountService;

    @Test
    public void springJunit5Test() {
        System.out.println(accountService);
    }

}
```

或者：

```java
package com.arc.spring.test;

import com.arc.spring.service.AccountService;
import org.junit.jupiter.api.Test;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.test.context.junit.jupiter.SpringJUnitConfig;

// @ExtendWith(SpringExtension.class) // 替代了 @RunWith(SpringJUnit4ClassRunner.class)
// @ContextConfiguration("classpath:transaction-by-annotation.xml")
// @SpringJUnitConfig = @ExtendWith + @ContextConfiguration
@SpringJUnitConfig(locations = "classpath:transaction-by-annotation.xml")
public class SpringJunit5Test {

    @Autowired
    private AccountService accountService;

    @Test
    public void springJunit5Test() {
        System.out.println(accountService);
    }

}
```
