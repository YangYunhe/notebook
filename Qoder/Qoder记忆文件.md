# Qoder 记忆文件

## 1. 用户级规则目录

- 目录：`~\.qoder-cn\rules`
- 作用：用户级（全局）规则目录，对该用户下的所有项目生效。
- 书写方式：每个规则为独立的 `.md` 文件，**必须在文件头加 YAML frontmatter 声明 `trigger`，否则规则不生效**；正文使用 Markdown。

```markdown
---
trigger: always_on
---
# 规则标题

规则正文……
```

`trigger` 的可选值与作用：

- `always_on`：常驻规则，每次请求自动注入上下文，无需手动引用。因每轮都占用上下文，规则内容应保持精炼。
- `glob`：按 glob 模式匹配文件，仅当涉及匹配的文件时生效。
- `model_decision`：由模型根据规则描述自行判断是否应用。
- `manual`：按需规则，仅在显式引用时加载。

## 2. 项目级记忆文件

- 目录：项目根目录
- 文件名：`AGENTS.md`
- 作用：项目级记忆文件，仅对当前项目生效。
- 书写方式：Markdown 文件，直接编写项目相关的规则与说明。

## 3. 客户端内部记忆库

- 位置：客户端内部数据库，非文件
- 作用：软件自动记录的用户偏好、踩坑经验、决策记录等，包含用户级和项目级记忆。
- 查看方式：`文件` → `首选项` → `Qoder IDE 设置` → `记忆` → `记忆列表`。

## 4. 项目规则文件

- 目录：项目根目录下的 `.qoder/rules/`
- 文件：`*.md`
- 作用：项目级规则文件，可提交进 Git 与团队共享。
- 书写方式：与第 1 节相同，每个规则为独立的 `.md` 文件，以 YAML frontmatter 声明 `trigger`，正文使用 Markdown。
