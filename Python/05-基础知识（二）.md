# 1. 输入与输出

## 1.1 输入

如果接收用户在键盘上输入一些字符，Python提供了一个**input**()函数，可以让用户输入字符串，并存放到一个字符串变量里。

语法：字符串变量 = input("提示信息")

```python
# Python 开始等待你的输入。这时，你可以输入任意字符，然后按回车完成输入。
input_str = input("请输入：")
# 输入完成后，不会有任何提示，刚才输入的内容存放到 input_str 变量里了
print("input_str 数据类型为：", type(input_str)) # input_str 数据类型为： <class 'str'>
# 输出 input_str 查看变量内容
print(input_str)
```

## 1.2 输出

（1）**普通输出**

```python
# 使用 print() 可将内容打印。
print("Hello Python") # Hello Python
# 多个内容之间可以使用逗号隔开。
print("Hello", "Python") # Hello Python
# 可以使用 end= 来控制 print() 以什么结尾。默认 \n
print("使用\\n结尾", end="\n")
print('使用""结尾', end="")
print("Hello")
# 使用\n结尾
# 使用""结尾Hello
```

（2）**格式化输出**

<1> 字符串中使用 % 占位

```python
int1 = 10
float1 = 3.14159
str1 = "int1 = %d, float1 = %f" % (int1, float1)
print(str1) # int1 = 10, float1 = 3.141590
```

格式符号列表：

| 格式符号 | 说明                               |
| -------- | ---------------------------------- |
| %d       | 十进制整数                         |
| %f       | 浮点数，%.nf 可指定显示小数点后n位 |
| %s       | 字符串                             |
| %o       | 八进制整数                         |
| %x       | 十六进制整数                       |
| %e       | 科学计数法                         |

<2> 字符串.format()

```python
# 方式1：不设置指定位置，按默认顺序
int1 = 10
float1 = 3.14159
bool1 = True
str2 = "int1 = {}, float1 = {}, bool1 = {}".format(int1, float1, bool1)
print(str2) # int1 = 10, float1 = 3.14159, bool1 = True
# 方式2：设置指定位置，不能和方式1混合使用
int1 = 10
float1 = 3.14159
bool1 = True
str2 = "int1 = {0}, bool1 = {2}, float1 = {1}".format(int1, float1, bool1)
print(str2) # int1 = 10, bool1 = True, float1 = 3.14159
# 方式3：设置参数
int1 = 10
float1 = 3.14159
bool1 = True
str2 = "int1 = {i1}, float1 = {f1}, bool1 = {b1}".format(i1=int1, f1=float1, b1=bool1) # int1 = 10, bool1 = True, float1 = 3.14159
```
<3> 数字格式化

```python
float1 = 31415.9
str2 = "{:*^20,.2f}".format(float1)
print(str2) # *****31,415.90******
```

- `*`：以`*`填充空白，不写默认以空格填充
- `^`：可选`<`、`^`、`>` 分别是左对齐、居中、右对齐
- `20`：数字宽度为20，数字长度不足20则进行填充
- `,`：可选，`,`和`_`，每3位进行分隔
- `.2f`：小数点后保留2位
