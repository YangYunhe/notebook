文件名中带有日期，日期就是所在目录的目录名。

需求：把所有日期目录下的以下文件移动到上一级：

```
DLA_AFP_O_DCP_WLC_PERS_SUB_WLT_INFO_${日期}.*
DLA_AFP_O_DCP_WLC_PERS_WLT_INFO_${日期}.*
DLA_AFP_O_DCP_WLC_CORP_WLT_INFO_${日期}.*

DLA_AFP_O_DCP_WLC_BKKP_TRAN_${日期}.*
DLA_AFP_O_DCP_WLC_BKKP_VS_TRAN_${日期}.*
DLA_AFP_O_DCP_WLC_TXN_JNL_${日期}.*
DLA_AFP_O_DCP_CBS_WLT_ACCT_BIND_${日期}.*
```

即每个目录下要移动走 9 组 18 个文件，12 个目录下总共要移动走 12 * 9 = 108 组 18* 9 = 162 个文件。

实现：

```bash
for dir in 202611{16..27}; do
    for file_prefix in \
        DLA_AFP_O_DCP_WLC_PERS_SUB_WLT_INFO \
        DLA_AFP_O_DCP_WLC_PERS_WLT_INFO \
        DLA_AFP_O_DCP_WLC_CORP_WLT_INFO \
        DLA_AFP_O_DCP_WLC_CORP_WLT_INFO_EXT \
        DLA_AFP_O_DCP_WLC_CORP_WLT_OPEN_JOURNAL \
        DLA_AFP_O_DCP_WLC_BKKP_TRAN \
        DLA_AFP_O_DCP_WLC_BKKP_VS_TRAN \
        DLA_AFP_O_DCP_WLC_TXN_JNL \
        DLA_AFP_O_DCP_CBS_WLT_ACCT_BIND; do
        file="${dir}/${file_prefix}_${dir}.*"
        [ -f "$file" ] && mv "$file" ./
    done
done
```

知识点：

- `[ -f "$file" ]`
  - `[ ]`是 `test` 命令的简写，**条件判断**
  - `-f`：判断后面的路径**是否是存在的普通文件**（不是目录、不是软链接）
  - `"$file"`：变量 file 加双引号，防止文件名含空格、特殊字符导致命令出问题
  - 返回 0（true）：文件存在
  - 返回非 0（false）：文件不存在
  - 等价写法：`test -f "$file"`
- `&&`
  - 之前的命令返回 0（true），继续执行后面的命令
  -  直接的命令返回非 0（false）：后面的命令直接跳过，不报错
