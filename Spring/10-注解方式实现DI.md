注解方式依赖注入 DI：

- @Autowired 根据属性数据类型自动装配
- @Qualifier 根据属性名称注入依赖
- @Resources 可以根据类型，也可以根据名称注入
- @Value 注入普通数据类型（8 个基本数据类型和 String）



# 1. @Autowired + @Qualifier

```java
package com.arc.spring.service.impl;

import com.arc.spring.dao.UserDao;
import com.arc.spring.service.UserService;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.beans.factory.annotation.Qualifier;
import org.springframework.stereotype.Service;

@Service
public class UserServiceImpl implements UserService {

    /**
     * @Autowired
     * 根据类型到容器中去寻找对应的对象，找到后给当前属性赋值
     * 不需要依赖 set 方法
     * 属性类型可以是接口，会自动匹配对应的实现类对象
     * 如果根据类型匹配到多个对象，则需要
     * @Autowired 配合 @Qualifier，可以通过名称注定注入的对象
     */
    @Autowired
    // @Qualifier(value = "userDaoImpl1") 如果属性名是 value，可以省略不写
    @Qualifier("userDaoImpl1")
    UserDao userDao;

    @Override
    public void addUser() {
        userDao.addUser();
    }
}

```

# 2. @Resource

```java
package com.arc.spring.service.impl;

import com.arc.spring.dao.UserDao;
import com.arc.spring.service.UserService;
import org.springframework.stereotype.Service;
import javax.annotation.Resource;

@Service
public class UserServiceImpl implements UserService {

    /**
     * @Resource
     * 根据类型到容器中去寻找对应的对象，找到后给当前属性赋值
     * 如果根据类型匹配到多个对象，则需要
     * @Resource(name = "xxx") 设置名称注入的对象
     * @Resource 是 javax.annotation 包下的类，不是 Spring 框架的类，且在 JDK 1.8 之后就没有了
     * 建议使用 @Autowired 注解，降低 Spring 框架与 JDK 的耦合度
     */
    @Resource(name = "userDaoImpl2")
    UserDao userDao;

    @Override
    public void addUser() {
        userDao.addUser();
    }
}
```



输出：

```
UserDaoImpl2 addUser...
```



# 3. @Value

Spring 配置文件中设置读取配置文件：

```xml
<!-- 读取 jdbc.properties 配置文件 -->
<context:property-placeholder location="classpath:jdbc.properties"/>
```



代码中注入基本类型：

```java
package com.arc.spring.service.impl;

import com.arc.spring.dao.UserDao;
import com.arc.spring.service.UserService;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.stereotype.Service;
import javax.annotation.Resource;

@Service
public class UserServiceImpl implements UserService {

    @Resource(name = "userDaoImpl2")
    UserDao userDao;

    @Value("张三")
    private String name;
    @Value("20")
    private Integer age;
    @Value("${driverClassName}")
    private String driver;
    @Value("${url}")
    private String url;
    @Value("${jdbc_username}")
    private String username;
    @Value("${password}")
    private String password;
    @Value("${initialSize}")
    private Integer initialSize;

    @Override
    public void addUser() {
        System.out.println(name);
        System.out.println(age);
        System.out.println(driver);
        System.out.println(url);
        System.out.println(username);
        System.out.println(password);
        System.out.println(initialSize);
        userDao.addUser();
    }
}
```
