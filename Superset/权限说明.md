# 1. Superset 权限体系

| 表                        | 含义                       | 例子                                       |
| ------------------------- | -------------------------- | ------------------------------------------ |
| `ab_role`                 | 角色                       | Admin、Alpha、Gamma、sql_lab、Public       |
| `ab_permission`           | 操作（动词）               | `can_read`、`can_write`、`menu_access`     |
| `ab_view_menu`            | 被操作的对象 / 菜单        | `Dashboard`、`Chart`、`SQLLab`、`Superset` |
| `ab_permission_view`      | 原子权限 = 操作 × 对象     | `can_read` + `Dashboard`                   |
| `ab_permission_view_role` | 角色与原子权限的多对多关联 | Admin 拥有 `can_read`+`Dashboard`          |

默认角色的权限：

| 角色    | 授权条数 | 定位                               |
| ------- | -------- | ---------------------------------- |
| Admin   | 226      | 几乎全部权限                       |
| Alpha   | 115      | 可读写 Dashboard / Chart / Dataset |
| Gamma   | 93       | 以只读 + 菜单可见为主              |
| sql_lab | 30       | SQL Lab 相关                       |
| Public  | 0        |                                    |

准备测试账号：

创建角色：**Settings → List Roles → + Role** 中查看/编辑。

创建角色：**Settings → List Users → + User** 中查看/编辑。

| 账号       | 密码           | 角色                                                         |
| ---------- | -------------- | ------------------------------------------------------------ |
| `admin`    | `admin`        | Admin                                                        |
| `alpha01`  | `Superset@123` | Alpha                                                        |
| `gamma01`  | `Superset@123` | Gamma                                                        |
| `sqllab01` | `Superset@123` | sql_lab                                                      |
| `public01` | `Superset@123` | Public                                                       |
| `ds01      | `Superset@123` | `role_flights_only`（自定义，仅 `datasource_access` 21 个数据集中的 `flights`） |
| `ds02`     | `Superset@123` | `role_flights_schema`（自定义，`datasource_access` flights + `schema_access` examples + `database_access` examples） |
