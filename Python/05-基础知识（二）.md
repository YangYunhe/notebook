# 1. 输入与输出

## 1.1 输入

如果接收用户在键盘上输入一些字符，Python提供了一个**input**()函数，可以让用户输入字符串，并存放到一个字符串变量里。

语法：字符串变量 = input("提示信息")

```python
# Python 开始等待你的输入。这时，你可以输入任意字符，然后按回车完成输入。
input_str = input("请输入：")
# 输入完成后，不会有任何提示，刚才输入的内容存放到 input_str 变量里了
print("input_str 数据类型为：", type(input_str)) # input_str 数据类型为： <class 'str'>
# 输出 input_str 查看变量内容
print(input_str)
```

## 1.2 输出

（1）**普通输出**

```python
# 使用 print() 可将内容打印。
print("Hello Python") # Hello Python

print("Hello", "Python") # Hello Python

print("使用\\n结尾", end="\n")
print('使用""结尾', end="")
print("Hello")
# 使用\n结尾
# 使用""结尾Hello
```

（2）**格式化输出**

<1> 字符串中使用 % 占位

```python
int1 = 10
float1 = 3.14159
str1 = "int1 = %d, float1 = %f" % (int1, float1)
print(str1) # int1 = 10, float1 = 3.141590
```

格式符号列表：

| 格式符号 | 说明                               |
| -------- | ---------------------------------- |
| %d       | 十进制整数                         |
| %f       | 浮点数，%.nf 可指定显示小数点后n位 |
| %s       | 字符串                             |
| %o       | 八进制整数                         |
| %x       | 十六进制整数                       |
| %e       | 科学计数法                         |

<2> 字符串.format()

```python
# 方式1：不设置指定位置，按默认顺序
int1 = 10
float1 = 3.14159
bool1 = True
str2 = "int1 = {}, float1 = {}, bool1 = {}".format(int1, float1, bool1)
print(str2) # int1 = 10, float1 = 3.14159, bool1 = True
# 方式2：设置指定位置，不能和方式1混合使用
int1 = 10
float1 = 3.14159
bool1 = True
str2 = "int1 = {0}, bool1 = {2}, float1 = {1}".format(int1, float1, bool1)
print(str2) # int1 = 10, bool1 = True, float1 = 3.14159
# 方式3：设置参数
int1 = 10
float1 = 3.14159
bool1 = True
str2 = "int1 = {i1}, float1 = {f1}, bool1 = {b1}".format(i1=int1, f1=float1, b1=bool1) # int1 = 10, bool1 = True, float1 = 3.14159
```
<3> 数字格式化

```python
float1 = 31415.9
str2 = "{:*^+20,.2f}".format(float1)
print(str2) # *****+31,415.90*****
```

- `*`：以`*`填充空白，不写默认以空格填充，填充字符写在`:`后面
- `^`：可选`<`、`^`、`>` 分别是左对齐、居中、右对齐，后面带宽度
- `+`：在正数前显示`+`，`-`可以在负数前显示`-`，`空格`表示在正数前加空格，写在对齐符号和宽度中间
- `20`：数字宽度为20，数字长度不足20则进行填充
- `,`：可选，`,`和`_`，每3位进行分隔
- `.2f`：小数点后保留2位

案例：

| 数字       | 格式      | 输出      | 描述                                                        |
| ---------- | --------- | --------- | ----------------------------------------------------------- |
| 3.1415926  | `{:.2f}`  | 3.14      | 保留小数点后两位                                            |
| 3.1415926  | `{:+.2f}` | +3.14     | 带符号保留小数点后两位                                      |
| -1         | `{:-.2f}` | -1.00     | 带符号保留小数点后两位                                      |
| 2.71828    | `{:.0f}`  | 3         | 不带小数                                                    |
| 5          | `{:0>2d}` | 05        | 数字补零（填充左边，宽度为2）                               |
| 5          | `{:x<4d}` | 5xxx      | 数字补x（填充右边，宽度为4）                                |
| 10         | `{:x<4d}` | 10xx      | 数字补x（填充右边，宽度为4）                                |
| 1000000000 | `{:.2e}`  | 1.00e+09  | 指数记法                                                    |
| 1000000    | `{:,}`    | 1,000,000 | 以逗号分隔的数字格式                                        |
| 0.25       | `{:.2%}`  | 25.00%    | 百分比格式                                                  |
| 13         | `{:>10d}` | 13        | 右对齐（默认，宽度为10）                                    |
| 13         | `{:<10d}` | 13        | 左对齐（宽度为10）                                          |
| 13         | `{:^10d}` | 13        | 中间对齐（宽度为10）                                        |
| 11         | `{:b}`    | 1011      | binary 二进制，把整数格式化为二进制字符串，不带 `0b` 前缀   |
| 11         | `{:d}`    | 11        | `d` = decimal，十进制整数格式，只用于 `int`                 |
| 11         | `{:o}`    | 13        | `o` = octal，八进制格式，只支持整数 int，输出不带 `0o` 前缀 |
| 11         | `{:x}`    | b         | `x` = hex，十六进制小写，仅支持整数，输出不带 `0x` 前缀     |
| 11         | `{:#x}`   | 0xb       | 小写十六进制，带前缀 `0x`                                   |
| 11         | `{:#X}`   | 0XB       | 大写十六进制，带前缀 `0X`                                   |
