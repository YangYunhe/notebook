# Qoder 记忆文件

## 1. 用户级规则目录

- 目录：`~\.qoder-cn\rules`
- 作用：用户级（全局）规则目录，对该用户下的所有项目生效。
- 书写方式：每个规则为独立的 `.md` 文件，以 YAML frontmatter 声明 `trigger`，正文使用 Markdown。

```markdown
---
trigger: always_on
---
# 规则标题

规则正文……
```

`trigger` 的取值与作用：

- `always_on`：常驻规则，每次请求自动注入上下文，无需手动引用，对全局始终生效。因每轮都占用上下文，规则内容应保持精炼。
- `manual`：按需规则，仅在显式引用时加载。

## 2. 项目级记忆文件

- 目录：项目根目录
- 文件名：`AGENTS.md`
- 作用：项目级记忆文件，仅对当前项目生效。
- 书写方式：Markdown 文件，直接编写项目相关的规则与说明。

## 3. 客户端内部记忆库

- 位置：客户端内部数据库，非文件
- 作用：软件自动记录的用户偏好、踩坑经验、决策记录等，包含用户级和项目级记忆。
- 查看方式：`文件` → `首选项` → `Qoder IDE 设置` → `记忆` → `记忆列表`。
